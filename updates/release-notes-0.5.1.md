# Slate 0.5.1

- **1-Click Chrome Web Store Extension Installs (Phase 2):**
  - Visiting any extension on `chromewebstore.google.com` now shows a clean floating **Add to Slate** bar that downloads the official CRX3 package, unpacks it, and activates it in Slate with one click (with live Installed / Remove state).
  - Added a **Chrome Web Store** quick-install bar and **Open Chrome Web Store** shortcut directly inside **Settings (`⌘,`) → Extensions** so you can also paste any Chrome Web Store URL or 32-character extension ID.
