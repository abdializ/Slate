# Slate 0.3.0

- Add Settings → Search with Google, DuckDuckGo, Bing, Ecosia, Startpage, Kagi, Brave Search, Qwant, and a custom search address.
- Add site search: type a site's name or alias, press Tab, and search with a removable site chip. Includes the supplied built-in sites and learns compatible OpenSearch sites separately for each space.
- Add editable keyword shortcuts such as “yt cats”.
- Make remote search suggestions opt-in, with no suggestions in private tabs. Cancel stale requests, refuse redirects, and avoid sending addresses, file paths, email addresses, or text that resembles a key.
- Improve address handling for local servers, private network addresses, IPv6 loopback, typed files, and addresses shown for editing.
- Replace page Find with isolated range-based matching, case and whole-word options, Unicode matching, dynamic page updates, and incremental match counts. Preserve PDF search and keyboard navigation.
- Apply the chosen search engine to the new-tab search field, address fields, and detached windows.

Use Slate → Check for Updates to install this release. Remote suggestions stay off until enabled in Settings → Search.
