# Slate 0.4.25

- **Minimalist Settings Redesign:**
  - Upgraded the Settings window to a full-size transparent titlebar (`740×540`), translucent macOS sidebar material (`NSVisualEffectMaterialSidebar`) with a crisp 1px hairline divider, and hover-reactive monochrome navigation items.
  - Rebuilt every Settings page (`Appearance`, `Search`, `General`, `Tabs`, `Downloads`, `Passwords`, `Privacy`, `About`) with responsive top-down scrollable layouts, quiet grouped cards (`11pt` continuous corners, hairline borders, inset row dividers), restrained monochrome controls (`SlateQuietButton`, small `NSSwitch`), and zero idle timers or animations.
