# Slate 0.5.5

- **Always Block Ads in Incognito (Independent of Normal Tabs):**
  - Added **Always Block Ads in Incognito** (enabled by default) in **Settings (`⌘,`) → Privacy**.
  - You can now turn off Slate's native **Ad & Tracker Blocker** in normal tabs (for example, when using Pie Adblock) while Incognito tabs automatically keep Slate's full native compiled ad blocker, Twitch ad blocker, and third-party ad iframe blocking active.
