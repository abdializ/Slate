# Slate 0.5.14

## New Features
- **Simplified Address Bar with Hover-to-Reveal Full URL:** At rest, the omnibox now displays a clean, simplified domain (e.g., `docs.google.com`, `youtube.com`, `localhost:3000`). Hovering over the address bar reveals the full URL, and clicking or pressing `⌘L` immediately opens the full URL for editing or copying.
