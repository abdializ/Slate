# Slate 0.5.3

- **Keep Extensions Exclusively in Settings + Master On/Off Toggle:**
  - Removed extension icons from the main browser toolbar so Slate's chrome stays completely clean and distraction-free.
  - Added a master **Enable Chrome Extensions** switch at the top of **Settings (`⌘,`) → Extensions** to turn all extensions on or off at once (unloading them from memory and hiding the Chrome Web Store install bar when off).
  - Added an **Open** button right inside each extension row in Settings → Extensions so you can open any extension's popup, Side Panel, or Options directly from Settings.
